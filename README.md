## 🎨 Design System & Upgrades (Per Improvement Guide)

1. **Color Palette**:
   - **Primary:** Deep Medical Teal (`#0F5C5C`) & Dark Teal (`#093E3E`)
   - **Accent:** Warm Gold (`#C8913A`) for booking actions and trust highlights
   - **Background:** Off-white (`#F7F9F8`) and Pure Card White (`#FFFFFF`)
   - **Text:** Slate Charcoal (`#1F2933` / `#323F4B`) for optimal readability
2. **Typography**:
   - **Headings:** Google Font **Lora** (elegant, trustworthy medical serif)
   - **Body:** Google Font **Inter** (clean, ultra-readable modern sans-serif)
3. **Monochrome SVG Line Iconography**:
   - Replaced all casual emojis with crisp, professional SVG line icons styled in deep teal.
4. **Medical Advertising Compliance**:
   - Eliminated absolute/guarantee claims ("100% cure", "proven guarantees").
   - Added prominent patient results disclaimer: *"Results may vary from person to person based on individual chronicity and constitution."*
   - Added mandatory footer disclaimer: *"Is website ki jaankari keval general information ke liye hai, doctor ki salah ka vikalp nahi."*
5. **New Features Added**:
   - **"Consultation Kaise Hoti Hai"**: 3-step consultation process (Detailed Case History &rarr; Individualized Prescription &rarr; Regular Follow-up).
   - **FAQ Accordion**: Common questions on homeopathic treatment speed, diet rules, allopathy compatibility, and appointments.
   - **Google Map Embed**: Responsive iframe embed for Balaji Polytechnic / Jain Diwaker Gali, Debari, Udaipur.
   - **Mobile Sticky Bottom Action Bar**: Fixed Call Now (`tel:8619106758`), WhatsApp, and Book Slot buttons for mobile visitors.
   - **SEO JSON-LD Schema**: Structured data (`MedicalClinic` / `Physician`) for local search visibility.
